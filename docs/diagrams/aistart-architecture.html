aiStart 架构

本地一体化 AI 工具箱：五个 Desktop 客户端共用一个本地网关，网关按请求协议与上游协议决定直通还是改写

一处配置，五个客户端

  • • 客户端只管把 base_url 指到 127.0.0.1:8931，协议不用改
  • • 各客户端的配置文件由 platform 层负责写入与还原，失败有兜底策略
  • • 上游密钥留在本地数据库，出站时才由网关代入

协议转换只在必要时发生

  • • 入站协议与上游协议一致时走直通：请求用客户端原文，响应与流逐字节转发
  • • 不一致才经规范层重建，规范形态以 Anthropic Messages 为基准
  • • 记账、判罚、事件日志在两条路径上跑的是同一份代码

可观测性落在本地

  • • 每个请求记下用量、状态码、错误原因与首字延迟
  • • 请求详情页能追溯原始报文，超长内容按上限截断后展示
  • • 客户端中途断开也有补偿记账，统计不会因为断线漏账

失败不隐藏，只换下一次

  • • 首个上游失败就直接把真实错误返回客户端，不做候选重试
  • • 满足条件时后台探测其它模型，成功后改写当前模型
  • • 点名指定模型的请求永远不被自动切换
